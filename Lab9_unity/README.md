# Lab 9 — Neon Relay

An interactive 3D scene built with Unity. The project includes a player controller, a third-person follow camera, obstacles, rotating objects, collectibles, and an in-game HUD.

## Open and run

1. In Unity Hub, select **Add project from disk**.
2. Choose this `Lab9` folder.
3. Open `Assets/Scenes/Lab9_Interactive3DScene.unity`.
4. Press **Play** in the Unity Editor.

The editor setup script creates the scene if it is missing. The project was last opened with Unity `6000.5.10f1`.

## Controls

- **WASD** or **arrow keys** — move
- **Space** — jump
- **R** — restart
